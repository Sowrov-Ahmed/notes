Git Commends:


git clone repo_URL               => To copy a repo from github to local drive

git status                       => Show current status of the local drive

git add .                        => All file will be added to github
git commit -m "give any msg"     => Versioning in local drive
git push                         => Sent file to github repo

rm -rf .git                      => Remove git from folder


**Process of uploading a local project in GitHub Repo**
git init                         => Initialize a new Git repository in the project folder.
git add .                        => Add all Files to Git
git commit -m "Initial commit"   => Commit the added files to the local repository
git remote add origin repo_URL   => Link the Local Repository to GitHub
git push -u origin main          => Push the Code to GitHub (Note: If using a different branch instead of main, replace main with the branch name.)


create a new repository on the command line
echo "# Frontend-Developer-Technical-Assessment" >> README.md
git init
git add README.md
git commit -m "first commit"
git branch -M main
git remote add origin https://github.com/Sowrov-Ahmed/Frontend-Developer-Technical-Assessment.git
git push -u origin main

…or push an existing repository from the command line
git remote add origin https://github.com/Sowrov-Ahmed/Frontend-Developer-Technical-Assessment.git
git branch -M main
git push -u origin main


Check your commit history        => git log --oneline

Important Notes:
🔄 Revert keeps history but creates new undo commits
💥 Reset permanently deletes subsequent commits
⚠️ "git reset --hard" permanently deletes uncommitted changes.
Use "git revert" for public/shared repositories to avoid rewriting history.
Always communicate with collaborators if you force-push (--force).


# Go back 1 commit               =>git reset --hard HEAD~1  
# or
# Go to a specific commit        =>git reset --hard <commit-hash>  

Revert (Create New Undo Commit)
If you want to keep a public history intact:
 # Creates a new commit that undoes changes   => git revert <commit-hash> 

Example:
Option 1: Revert (Safe)
# Undo changes from all commits after 67ca916    => git revert 67ca916..HEAD
# Push normally                                  => git push origin main

Option 2: Reset (Destructive)
# Completely remove all commits after 67ca916    => git reset --hard 67ca916
# Force push to GitHub                           => git push --force origin main
